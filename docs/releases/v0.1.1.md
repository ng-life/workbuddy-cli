WorkBuddy Go CLI 维护版本，修复 Buddy 生命周期，并增加 GitHub Actions 多平台发布流程。

## 修复

- 先领旅行礼物，确认空闲后开 Buddy，最后派出，避免覆盖在途记录或未领取的礼物。
- 旅行中、状态未知或领奖失败时跳过开盒与派出；旅行名额用尽仍允许打开空闲 Buddy。
- 派出接口明确返回 `403 + no active buddy` 时正常跳过；其他认证或权限失败继续报错。
- 后续派出失败时保留本轮此前已到账的奖励记录。

## 发布包

提供 macOS、Linux、Windows 的 amd64 / arm64 安装包及 `SHA256SUMS`。版本号从标签注入二进制，包内保留配置示例、使用文档和上游 MIT 声明。

下载匹配系统与架构的包，校验后解压，将二进制放入 PATH 中，再执行 `workbuddy-cli version` 和 `workbuddy-cli doctor`。

## 验证与边界

CI 执行格式检查、race 测试、`go vet`、六个平台交叉编译、校验文件验证及 Linux amd64 安装包版本冒烟检查。其他平台的交叉编译不代表完成原生运行测试；macOS 包未经 Apple Developer ID 签名或公证。

本机开发版本已完成真实 `auto` 验证：当日已签到、旅行名额用尽、无抽奖机会及能量不足时正确跳过相应操作。CI 不使用真实账号凭据。
